# Claude Notify - התראות Windows ל-Claude Code

תוכנה קטנה שיושבת בשורת המשימות. כש-Claude Code מסיים להשיב, קופצת התראה עם סיכום קצר של התשובה.

## מה היא עושה
- מציגה התראה עם סיכום של ההודעה (עד 30 מילים), או את תחילתה אם הסיכום כבוי או נכשל.
- לחיצה על ההתראה מעבירה את חלון VS Code של הפרויקט לקדמה.
- לא מציגה התראה אם חלון העורך גלוי על המסך (מלא או חלקי). אם הוא ממוזער או מכוסה לגמרי, היא מציגה.
- כיבוי והפעלה בלחיצה ימנית על האייקון בשורת המשימות.

## התקנה
1. להריץ את `ClaudeNotify.exe` (לא דורש התקנה או הרשאות מנהל).
2. בחלון ההגדרות ללחוץ **"התקן חיבור ל-Claude Code"**.
3. אם ההתראות לא מופיעות: ב-Claude Code להקליד `/hooks` פעם אחת, או להפעיל אותו מחדש.

הכפתור מעתיק את התוכנה ל-`%LOCALAPPDATA%\ClaudeNotify` ומוסיף Stop hook ל-`%USERPROFILE%\.claude\settings.json`. נוצר גיבוי `settings.json.bak` והגדרות אחרות לא נפגעות. החיבור חל על כל הפרויקטים.

כדי שהתוכנה תעלה עם Windows, לסמן **"הפעל עם Windows"** ולשמור.

## הסרה
בחלון ההגדרות: **"הסר חיבור"**, ואז יציאה מהאייקון ומחיקת התיקייה `%LOCALAPPDATA%\ClaudeNotify`.

## הגדרות
- **סיכום ההודעה** - מריץ `claude -p` עם Haiku, ולוקח כ-15 שניות. נספר על המנוי. כשהוא כבוי מוצגת תחילת ההודעה מיד.
- **חלון התראה משלי** - חלון בפינת המסך שלא מפריע לעבודה. לחיצה עליו מעבירה ל-VS Code, והזמן שלו נעצר כשהעכבר מעליו.
- **זמן הצגת ההתראה** - 2 עד 60 שניות (ברירת מחדל 8). פועל כשהחלון המשלי מופעל. ההתראה הרגילה של Windows נשלטת בידי Windows ומתעלמת מהערך הזה.
- **מיקום ההתראה** - פינה ימנית למטה (ברירת מחדל) או שמאלית למטה. פועל עם החלון המשלי.
- **מספר מילים** - 5 עד 60.
- **תהליכי העורך** - ברירת מחדל: `Code, Code - Insiders, Cursor`.

## דרישות
- Windows 10/11 (.NET Framework 4.8 מובנה).
- Claude Code (התוסף ל-VS Code או שורת פקודה).

## הערות
- הקובץ לא חתום, ולכן Windows SmartScreen עשוי להזהיר בהרצה ראשונה: "מידע נוסף" ← "הפעל בכל זאת". קוד המקור נמצא בתיקייה `src` ואפשר לבנות בעצמך עם `build.cmd`.
- אם ההתראה לא קופצת, לבדוק שמצב "נא לא להפריע" / Focus assist כבוי.
- יומן לבדיקת תקלות: `%APPDATA%\ClaudeNotify\log.txt` (מכיל רק ספירות ולא את תוכן ההודעות).
- כדי לפתוח את ההגדרות: לחיצה כפולה על האייקון, או הרצה חוזרת של ה-exe.
